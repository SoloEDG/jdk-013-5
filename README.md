# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 无障碍叙事通道

不使用鼠标也能完整探索全景故事：

- 聚焦舞台后用 `↑/↓`（或 `←/→`）在当前时间窗内的故事目标间移动，画面会平滑转向目标（系统开启「减少动态效果」时瞬时跳转，场景变化改由文字播报传达）；
- `Enter` 打开当前目标，`Esc` 关闭热点详情 / 关于面板；访谈面板内 `Esc` 返回主线并把焦点还原到进入前的位置；
- `N` 口述当前场景（章节、地点、时间与每个目标的方位 / 时间窗 / 人物提示），`M` 在「双通道 / 仅语音 / 仅读屏文字」三种播报模式间切换；
- 热点按钮采用 roving tabindex，读屏名称包含方位、时间窗与人物信息；目标排序规则全应用统一（方位差 → 仰角 → 开始时间 → id），切章、回访与缩放后顺序保持一致；
- 语音与 live region 文字共用一个播报网关：文字始终先可用，语音引擎加载慢不影响阅读；同一句话有去重冷却，配合播报模式可避免系统读屏与语音合成重复朗读；
- 自动播报不会移动焦点，在探索手记的文本框中输入时所有自动讲述自动静音；
- 热点时间窗结束时，已打开的文字卡片保留可读完，但按钮与操作项立即停用，它不再是当前场景中可点击的对象。
